# Economics arcade skins

The shared arcade (js/arcade/skins.js) already ships Economics sub-skins for all
four games that map onto Equilibrium's three arcade games, so nothing was ported:

| Equilibrium game | Shared engine | Skin in skins.js |
|---|---|---|
| Market Run (one-tap runner: dodge red downturn blocks, accent-green runner) | runner | "Market Run" |
| Ticker Match (memory grid of 📈 📉 💹 🏦 🪙 💵 📊 🧾 ⚖️ 🏗️, against a closing-bell clock) | pairs | "Ticker Match" |
| Bargain Hunt (drag a basket; catch green "bargains", avoid red "overpriced") | catch | "Bargain Hunt" |
| — | crush | "Ticker Crush" |

Visual theme, if the skins are revisited: Ledger palette (deep green #07100c,
accent #4ade80, brass/warn #fbbf24, bad #f87171). Runner obstacles read as
falling price bars / "recession" blocks, pickups as coins 🪙 and 📈. Match-3 /
2048 ladders can climb the money hierarchy 🪙 → 💵 → 💰 → 🏦 → 🏛️ → 🌏.
The arcade paid nothing in Equilibrium and pays nothing here.
